# IP Addressing 

# What I learnt: 

# There are two types or kinds of IP addresses, that is IP version 4 and version 6 (IPv4 and IPv6)

# IPv4(Internet protocol version 4): this is is a series of 4 numbers separated by a period or it is a 32 bit number with 4 octet or 8 bits separated by a period. It is combined with a 4 octet value (eg: 255.255.255.0) known as the subnet mask that is used together with the IP address to identify what IP subnet a device is on.There are 5 classes of IPv4 addresses and they are Class A through to E.
# An example of IPv4 IP addresses is 192.168.0.0

# There is a loopback IP address that is the home address of your machine which is of the range 127.0.0.1 - 127.255.255.254

# There are Reserved IP addresses: these IP addresses are set aside for future use or for hosting purposes; they range from 240.0.0.1 - 254.255.255.254 and all Class E IP addresses are also reserved IP addresses. Three different ranges of IP addresses are set aside for private addressing and they are : 1. 10.0.0.0 - 10.255.255.255( Class A ans has 24 bits), 2. 172.16.0.0 - 172.31.255.255 ( Class B), 3. 192.168.0.0 - 192.168.255.255 ( Class C)

# IPv4 supports up to 4.9 billion devices


# IPv6 (Internet protocol version 6): IPv6 (Internet Protocol version 6) is the newer version of the Internet Protocol designed to replace IPv4. Its main purpose is to solve IPv4 address exhaustion by providing a vastly larger address space. It is a 128-bit addresses compared to IPv4's 32-bit addresses. It written in hexadecimal, separated into 8 groups. It supports approximately 3.4 × 10³⁸ unique addresses and it has  built-in support for address auto-configuration. It eliminates the need for broadcast; IPv6 uses multicast and anycast instead.


# An IPv6 address looks like:

# 2001:0db8:85a3:0000:0000:8a2e:0370:7334

# Leading zeros can be removed:

# 2001:db8:85a3:0:0:8a2e:370:7334

# Consecutive groups of zeros can be compressed using ":::"

# 2001:db8:85a3::8a2e:370:7334

# '::' can only be used once in an IPv6 address.
