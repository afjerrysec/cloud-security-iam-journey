## The OSI 

# In my own words: the OSI (Open Systems Interconnection) model a model that is used in IT; it describes how data moves over a network. 

# It consist of 7 layers namely: Application, Presentation, Session, Transport, Network, Data Link and the Physical Layer.

# Each Layer plays a role in the traversal od data or information over a network.

# 7. Application Layer: This layer is responsible for whatever is seen in the output device of the user. It provide networking service to the user applications such as Web Browsers, emails and file transfers.


# 6. Presentation Layer: this layer translates data formats from machine dependent for to a from understandable by all machine, it takes cre of character encoding, it encrypts and decrypts data and compresses and decompresses data.


# 5. Session layer: this layer provide communication management between devices, this layer is also responsible for starting, stopping and restarting communication between devices.


# 4. Transport Layer: this layer ensures reliable delivery of data, checking of errors, controlling of flow of data and dividing (segmentation) of data.


# 3. The Network Layer: also known as the router layer; this layer is used by the router to to forward network traffic over a network. it handles logical addressing (IP addressing) an routing so that data can travel between different networks. Data is broken down into small bit know as packets. It also involves Subneting ( sub dividing network into smaller networks).


# 2. The Data Link Layer: this layer is also known as the MAC address layer or the "Switching" layer. it forms the foundation or it is the fundamental for communication between devices on the same network. It handles physical (MAC) addressing, framing ( divides packets into segments), and it also handles error detection on the local network.


# 1. The Physical Layer: this layer describes how data is sent as physical signals via cables, fiber. It involves the transmission of raw bit as electrical, optical or radio signals through cables or wireless media.



# A real world or a practical application or example of how this works is the opening of a web browser.

# Application layer: the browser creates an HTTP request(which is the a network services)

# Presentation layer: The data that would be sent may be encrypted with TLS/SSL

# Session Layer: This layer maintains  the connection between the browser and the server.

# Transport Layer: Transmission Control Protocol (TCP) breaks down the request into segments and ensures that data is delivered

# Network Layer: The IP adds source and destination IP addresses and it routes the packets.

# Data Link Layer: Ethernet/Wi-fi adds MAC address and creates frames

# Physical Layer: Bits are transmitted through Wi-Fi or a network Cable.
